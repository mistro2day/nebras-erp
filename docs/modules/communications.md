# موديول الاتصالات والمراسلات الفورية (Communications & Instant Messaging System)

يوفر هذا الموديول منصة متكاملة لإدارة قنوات الاتصال، ومزودات الخدمة (WhatsApp, SMS, Email, Push Notifications)، وقوالب الرسائل الديناميكية المحفوظة مركزياً على قاعدة بيانات **نيون (Neon PostgreSQL)**، وسجل حركة الرسائل الفورية مع دعم معالجة الأحداث التلقائية (Event-Driven Messaging) والربط بخادم **Evolution API**.

---

## 1. المعمارية العامة ومزودات الخدمة (Architecture & Providers)

### أ. خادم واتساب إيفولوشن وقاعدة بيانات نيون (Evolution API & Neon PostgreSQL)
- **محرك الربط**: يعتمد النظام على `EvolutionWhatsAppClient` ومحرك `Baileys` مفتوح المصدر للتواصل المباشر مع خادم Evolution API لإرسال واستقبال رسائل الواتساب.
- **قاعدة البيانات وقوالب الرسائل**: تُحفظ وتُدار جميع قوالب الرسائل وسجلات الإرسال وحالات التسليم مركزياً وبشكل متزامن عبر قاعدة بيانات **نيون (Neon PostgreSQL)** السحابية.
- **المصادقة والاتصال**:
  - قراءة المتغيرات المركزية `EVOLUTION_API_URL` و `EVOLUTION_API_KEY` و `EVOLUTION_INSTANCE_NAME` تلقائياً من إعدادات النظام (`settings.py` / البيئة).
  - دعم تمرير مفتاح المصادقة عبر الترويسة `apikey`.
  - معالجة وإعادة المحاولة التلقائية عند انقطاع الاتصال أو بطء الشبكات.

### ب. دعم تعدد مزودي وشرائح الواتساب (Multi-Instance WhatsApp Providers)
- يتيح النظام لمدارس نبراس إضافة أكثر من مزود خدمة واتساب (أرقام وشرائح هاتف مختلفة) لتقسيم العمليات (مثلاً: شريحة مخصصة للقبول والتسجيل وشريحة أخرى للإدارة المالية والخزينة).
- لكل مزود:
  - اسم جلسة مستقل (`instance_name`) في محرك Evolution API.
  - رمز استجابة سريع منفصل (**QR Code**) مقترن برقم الشريحة الخاص بتلك الجلسة.
  - مفتاح فحص اتصال مستقل (`connectionState`) وحصة إرسال يومية منفصلة.
- توفر واجهة قنوات ومزودات الخدمة (`/communications/channels`) زر مسح QR كود لكل مزود على حدة، واختبار الاتصال التشخيصي لكل شريحة بشكل مستقل ودقيق.

## 2. الإرسال التلقائي للأحداث (Event-Driven Automatic Messaging)

### أ. إشعار ترحيب واعتماد تسجيل الطالب الفعلي (`ADM_ENROLLED`)
- **المحفز (Trigger)**:
  1. اعتماد طلب القبول ونقل الطالب كطالب مسجل وفعلي في النظام (`create_student_from_applicant`).
  2. إنشاء وتسجيل الطالب يدوياً عبر معالج التسجيل السريع (`create_student_manually`).
- **المستلم**: رقم الواتساب المعتمد لولي الأمر (`whatsapp_phone`) المحفوظ في جدول علاقات العائلة (`StudentFamilyRelation`).
- **المحتوى المعتمد واللائحة**:
  - ترحيب رسمي باسم ولي الأمر واسم الطالب.
  - إرفاق الرقم الأكاديمي المولد للطالب والصف والمرحلة الدراسية المقيد بها.
  - إدراج **لائحة واشتراطات التسجيل المعتمدة بالسودان**:
    1. الالتزام بالزي المدرسي الموحد والدوام الصباحي في المواعيد المقررة.
    2. الالتزام بالجدول الزمني لسداد الأقساط والرسوم وفق التقويم المالي المعلن.
    3. المحافظة على البيئة المدرسية والممتلكات العامة واللوائح السلوكية.
- **القالب المركزي**: `ADM_ENROLLED`.

### ب. إشعار سداد الرسوم وإصدار سند القبض المالي (`PAYMENT_RECEIPT`)
- **المحفز (Trigger)**:
  - صدور وترحيل سند قبض مالي وتسجيل دفعة سداد في موديول مالية الطلاب (`PaymentService.receive_payment`)، سواء عند سداد قسط دراسي، أو دفع الرسوم المباشرة، أو السداد الفوري الأولي أثناء التسجيل.
- **المستلم**: رقم الواتساب المعتمد لولي الأمر (`whatsapp_phone`).
- **المحتوى والتفقيط السوداني**:
  - اسم ولي الأمر واسم الطالب ورقم سند القبض الرسمي (`RCP-YYYY-XXXX`).
  - المبلغ المسدد بالجنيه السوداني (`ج.س`) مع **التفقيط العربي الكامل** (مثال: `خمسمائة ألف جنيه سوداني فقط لا غير`) باستخدام مكتبة `tafqeet_arabic`.
  - تاريخ السداد، طريقة الدفع المصرفية المعتمدة (تطبيق بنكك، فوري، نقداً، إلخ).
  - الرصيد المتبقي المستحق على حساب الطالب بعد خصم الدفعة.
- **القالب المركزي**: `PAYMENT_RECEIPT`.

## 3. قاموس المتغيرات الديناميكية (Dynamic Variables Dictionary)

| رمز المتغير | مسمى المتغير | المجال | مثال توضيحي |
| :--- | :--- | :--- | :--- |
| `{{school_name}}` | اسم المدرسة / المستأجر | الهوية المؤسسية | مدارس المورد النموذجية (مشتق ديناميكياً من المستأجر) |
| `{{student_name}}` | اسم الطالب الكامل | شؤون الطلاب | خالد عثمان إبراهيم الكباشي |
| `{{student_code}}` | الرقم الأكاديمي للطالب | شؤون الطلاب | STU-2026-0841 |
| `{{grade_level}}` | الصف / المرحلة | شؤون الطلاب | الصف العاشر الثانوي |
| `{{guardian_name}}` | اسم ولي الأمر | أولياء الأمور | عثمان إبراهيم الكباشي |
| `{{guardian_phone}}` | هاتف ولي الأمر | أولياء الأمور | 0912345678 |
| `{{receipt_number}}` | رقم سند القبض المالي | المالية (ج.س) | RCP-2026-0042 |
| `{{amount}}` | المبلغ المالي | المالية (ج.س) | 120,000.00 |
| `{{amount_words}}` | المبلغ تفقيطاً بالكلمات | المالية (ج.س) | مائة وعشرون ألف جنيه سوداني فقط لا غير |
| `{{remaining_balance}}` | الرصيد المتبقي المستحق | المالية (ج.س) | 80,000.00 |
| `{{payment_date}}` | تاريخ السداد | المالية (ج.س) | 2026-09-22 |
| `{{payment_method}}` | وسيلة الدفع | المالية (ج.س) | تطبيق بنكك (Bankak) |
| `{{registration_policy}}` | لائحة واشتراطات التسجيل | القبول والتسجيل | لائحة الانضباط المدرسي والزي والرسوم |

## 4. لوحة تحكم وسجل الرسائل الفورية (`/communications/dashboard`)

- **تأصيل البيانات الحقيقية (Real-Time Live Data)**:
  - إلغاء البيانات الوهمية والتجريبية السابقة (`FALLBACK_MESSAGES`) وتغذية الجدول مباشرة بسجل حركة الرسائل الفعلية الصادرة من قاعدة البيانات.
  - ترقية دالة تحويل البيانات `toArray` لتدعم بنية استجابات Nebras ERP (`res.data` و `res.data.results`).
  - معالجة التوقيت والتسجيل الزمني الذكي: اعتماد `created_at` كبديل عند غياب `sent_at` لضمان ظهور كافة الرسائل (الناجحة، الفاشلة، أو المعلقة) بتوقيتها الفعلي في الجدول، ومنع انحدارها إلى قاع السجل.
  - استخلاص أسماء وأرقام المستلمين الحقيقية من كائن المستلمين `recipients` أو المتغيرات البديلة.
  - تحديث بطاقات المؤشرات الإحصائية (رسائل اليوم، نسبة نجاح التسليم، الرسائل الفاشلة، القنوات النشطة) ديناميكياً من بيانات السجلات الحقيقية المحملة.
- **التطبيع الدولي التلقائي للأرقام السودانية (Phone Normalization)**:
  - تطبيع أرقام الهواتف والواتساب تلقائياً بإضافة البادئة الدولية السودانية (`+249`) لأي رقم محلي مكون من 9 أرقام في الواجهة والخلفية.
- **زر التحديث الفوري (Live Refresh)**:
  - إضافة زر `🔄 تحديث البيانات` في شريط الترويسة العلوي لإعادة تحميل السجل والإحصائيات فورياً بضغطة زر واحدة دون الحاجة لتحديث الصفحة بالكامل.
- **التتبع الزمني لحالة الرسائل**:
  - عرض المخطط الزمني التفصيلي لمسار كل رسالة (في الطابور ➔ أُرسلت ➔ تم التسليم ➔ قُرئت) أو بيان سبب الفشل بدقة مع كود الحالة من المزود الخارجي (`external_status`).
